## 🖨️ Comment l'utiliser

### Option 1 : Ouvrir dans un navigateur
```bash
# Windows
start dossier_petition.html

# Mac
open dossier_petition.html

# Linux
firefox dossier_petition.html
```

### Option 2 : Imprimer en PDF
1. Ouvrir le fichier dans le navigateur
2. **Ctrl+P** (Windows/Linux) ou **Cmd+P** (Mac)
3. Sélectionner imprimante **"Imprimer en PDF"** ou **"Save as PDF"**
4. Réglages recommandés :
   - **Format :** A4
   - **Marges :** Normales ou Moyennes
   - **Orientation :** Portrait
   - **Arrière-plan :** ✅ Activé (pour les dégradés)
5. Cliquer **Imprimer** ou **Enregistrer**

### Option 3 : Exporter en PDF avec Chrome/Edge
1. Ouvrir dans Chrome ou Edge
2. Menu **⋮** → **Imprimer**
3. Destination : **Enregistrer en PDF**
4. Cliquer **Enregistrer**

### Option 4 : Envoyer par email
- Imprimer en PDF (voir Option 2)
- Joindre le PDF à votre email
- Envoyer aux destinataires

## 🔧 Personnalisation

### Modifier le contenu
Ouvrir `dossier_petition.html` avec un éditeur texte :
- Texte : Chercher et remplacer facilement
- Statistiques : Mettre à jour les chiffres
- Images : Remplacer les URLs Unsplash
- Lien pétition : Mettre à jour `https://c.org/dR7wYWkXQN`

### Modifier les couleurs
```html
<!-- Ligne ~12 dans le <style> -->
:root {
    --toulouse: #0F3460;  /* Changer le bleu */
    --tlemcen: #D84315;   /* Changer l'orange */
}
```

### Ajouter plus de pages
Copier-coller une section `<div class="page page-content">` et adapter le contenu.
